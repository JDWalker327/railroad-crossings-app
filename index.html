Install this app

Choose Your Railroad

Select your primary railroad. Your choice will be saved so the app opens directly to it next time.

You can always switch railroads using the Change Railroad button.

Browse Railroads

Filter nationwide railroad crossings by Class I railroad tabs or by selecting a non-Class-I carrier.

Lookup

Search all crossings by DOT number or subdivision.

💡 Search by DOT # — type a crossing number and tap Lookup DOT.
Search by Subdivision — type a subdivision name to see matching results, then tap one to load its crossings.
